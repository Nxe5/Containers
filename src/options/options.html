Better Containers

YouTube, Gmail, GitHub, and Amazon each open in their own container. Everything else can open in a disposable Temporary Container.

Global settings

Vault

Site credentials, payment methods, and proxy passwords are stored in an encrypted vault protected by a master password you choose here. The master password is never stored and never leaves the browser.

 
 

Forgot your master password?

There is no password recovery — the vault key is derived only from your master password, so it can't be recovered. Resetting permanently deletes every saved credential, payment method, address, and proxy password so you can start over.

Vault unlocked

Built-in company containers

One domain per line. Saving replaces the built-in list for that company. Use the reset button to restore defaults.

Custom containers

Add your own containers — e.g. Work, Banking, Shopping. Give each a name, color, icon, and optional domain list. They behave exactly like the built-in companies and show up in the popup.

Site credentials

Used by the popup's "Fill login" action and by the native-messaging bridge below, whenever the vault is unlocked.

Website Account Password Container

Payment methods

Full card numbers and CVVs are stored in the encrypted vault at your request. This is not a PCI-compliant system — treat your master password and this browser profile with the same care as the cards themselves.

Addresses

A per-container address book — shipping/billing addresses you can assign to a specific container, stored in the encrypted vault.

User overrides

Always open a specific hostname in a chosen container. Highest priority.

Hostname / domain Container

Native messaging bridge

Lets a local script (e.g. a Playwright automation) request stored credentials through native-host/index.js. Run scripts/install-native-host.sh once to register it with Firefox, then generate a token below — requests only succeed while the vault above is unlocked, and the master password itself is never sent over this bridge. See the README for the full protocol.
