Built-in company containers

One domain per line. Saving replaces the built-in list for that company. Use the reset button to restore defaults.

Custom containers

Add your own containers — e.g. Work, Banking, Shopping. Give each a name, color, icon, and optional domain list. They behave exactly like the built-in companies and show up in the popup.

User overrides

Always open a specific hostname in a chosen container. Highest priority.

Native messaging bridge

Lets a local script (e.g. a Playwright automation) request stored credentials through native-host/index.js. Run scripts/install-native-host.sh once to register it with Firefox, then generate a token below — requests only succeed while the vault above is unlocked, and the master password itself is never sent over this bridge. See the README for the full protocol.
